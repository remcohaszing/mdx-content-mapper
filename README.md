# `mdx-content-mapper`

A TypeScript content mapper for MDX content.

The goal is to eventually merge this into [mdx-analyzer](https://github.com/mdx-js/mdx-analyzer) to
replace `@mdx-js/typescript-plugin`.

## Installation

```sh
npm install mdx-content-mapper
```
